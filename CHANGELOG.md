# Changelog

## 0.2.0 — first public release
- Stacks shown as flat, numbered lists under a coloured **Stack** header; forks nest.
- Drag and drop to reorder; each branch is rebased in its own git worktree, with conflict pause/resume.
- **Files** under each PR: only that PR's changes vs the PR below it, with diffs.
- Viewed checklist per file/folder, synced with GitHub's "Viewed" checkboxes.
- **Only My PRs / Everyone's PRs** filter; other people's PRs are view-only.
- Right-click **Checkout Branch**; open worktree / terminal / PR.
- Finds `gh` even when the editor is launched from the Dock.
